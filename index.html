How Kruti Dev Visual Rendering Works

Kruti Dev 010 is an 8-bit glyph font. In standard fonts it looks like English ASCII letters (for example, Hkkjr). By applying the Kruti Dev font-face to the browser canvas, the app converts those ASCII characters into authentic Devanagari shapes (भारत).

How to use in Microsoft Word:
  1. Click Copy in this tool.
  2. Paste into your Word document.
  3. Highlight the pasted text.
  4. Select Kruti Dev 010 from your software's font dropdown.
  5. All letters, conjuncts, and matras will render in Devanagari.
